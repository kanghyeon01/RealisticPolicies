# Realistic Policies — 참고문헌

패러독스 모드 페이지에 올릴 참고문헌 목록이다. 모드의 공식과 시작값이 어디서 왔는지는 docs/PLAN.md §5~§7, §10, §15에 적혀 있다.
- 국내 논문은 원문 PDF(`문서/Realistic Policies 자료/논문`)의 첫 쪽에서 서지 정보를 옮겼다. "확인 필요"는 원문에서 찾지 못한 항목이다.
- 해외 문헌과 이론은 설계에 쓴 것만 적었다. 학술지 논문의 권호·쪽수는 출판사 서지 정보(Crossref, JSTOR)와 대조했다 (2026-11-07). 책과 보고서의 서지, 논문의 내용은 원문과 대조하지 않았다.
- 정렬: 분야별, 저자 가나다·알파벳순.
