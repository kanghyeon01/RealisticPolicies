# 작업 B: 참고문헌 확인과 보충 (문서)

## 배경
- 파일: `C:\Users\khkim\source\CS2Mods\RealisticPolicies\docs\REFERENCES.md` (참고문헌), `docs\CONCEPTS.md` (핵심 개념).
- 두 문서는 나중에 외부 페이지에 공개된다. 서지 정보가 정확해야 한다.

## 할 일
1. `REFERENCES.md`에서 "(확인 필요)", "(저자 확인 필요)", "(쪽수 확인 필요)", "(권호·쪽수 확인 필요)", "(판·연도 확인 필요)"가 붙은 항목을 모두 찾아, 웹 검색(KCI, RISS, DBpia, Google Scholar, 출판사 페이지)으로 저자·연도·제목·학술지·권(호)·쪽을 확인한다.
   - 확인되면 그 줄을 완전한 서지로 고치고 표시를 지운다.
   - 확인이 안 되면 고치지 말고 그대로 둔다.
2. `CONCEPTS.md`에 "(저자, 연도)"로 나오는데 `REFERENCES.md`에 없는 문헌을 찾아, 완전한 서지로 `REFERENCES.md` 끝의 새 절 `### 핵심 개념의 고전 문헌`에 가나다·알파벳 순으로 추가한다. (예: Stigler 1971, Olson 1965, Granovetter 1978, Newman 1972 등)
3. 해외 문헌 서지 형식은 기존 항목과 같게: `저자 (연도). 제목. 학술지, 권(호), 쪽.` 국내 문헌은 `저자 (연도). 제목. 『학술지』, 권(호), 쪽.`

## 지킬 것
- 문헌의 내용 요약, 수치, 다른 문장은 바꾸지 않는다. 서지 정보만 고치거나 더한다.
- 다른 파일은 건드리지 않는다. 커밋하지 않는다.
- 추측으로 채우지 않는다. 원본(학술지 페이지, KCI 상세, DOI)에서 확인한 것만 쓴다.
