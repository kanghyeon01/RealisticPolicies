## 2. 오늘 알게 된 것

- **생계 지원:** 시험 도시에서 중위소득 ¢2,720의 32% = ¢870 아래가 13.0%(16,881 / 129,848가구). 필요 사회복지직 1,841명 → 280명.

- **폭동 범죄 위치 실패:** 기능은 맞게 동작했습니다. 시험이 저장 뒤 이어진 앞 폭동의 범죄를 정리 시험 폭동의 도로와 비교한 것이 원인이었습니다.

## 5. 시험 띄우는 법 (요약, 자세한 것은 `docs/MEMO.md` "시험")
1. 게임이 꺼진 상태에서 `ModsData/RealisticPolicies/selftest.flag`에 `save:RP SelfTest RiverPort;changed`(또는 `;protests`)를 씁니다. 시험 저장 `RP SelfTest RiverPort`는 이미 있습니다(11-09 사본).
2. `Start-Process explorer.exe 'steam://rungameid/949230'`으로 띄우고, Paradox Launcher의 **PLAY는 직접 누릅니다**(agent-desktop으로 `PLAY` 버튼을 찾아 클릭). 사용자에게 누르라고 하지 않습니다.
3. `Logs/RealisticPolicies.log`에서 `[FAIL]`·`Result:`를 봅니다. 결과는 끝날 때 `ModsData/RealisticPolicies/selftest/report.txt`에 써집니다. `;changed` 약 15분, `;protests` 약 8~10분, `;details` 약 4분.
4. 감시 스크립트에 `| head`를 붙이면 줄이 버퍼에 묶여 알림이 오지 않습니다.
5. 빌드가 15~20초에 끝나도 Burst 파일(`*_win_x86_64.dll` 등)이 새 시각으로 배포됐으면 정상입니다.
